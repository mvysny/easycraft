# EasyCraft

EasyCraft is a block-building game for young kids that runs in a web browser: walk around a
small island, take blocks away and build with twenty kinds of block. There are no monsters, no
damage and nothing to install — double-click `index.html` and play.

## Playing

Open `index.html` in a browser (Chrome, Firefox, Edge or Safari); no internet is needed. Click
**Play!**, then:

| Key | Does |
|---|---|
| Mouse | look around |
| W A S D, ↑ ↓ | walk |
| ← → | turn |
| Space | jump, swim up |
| Left click | take a block away |
| Right click | put a block down |
| 1–0, mouse wheel | pick a block |
| F | fly on/off (Shift goes down) |
| H | go back home |
| Esc | menu |

Walking into a one-block step hops up it. The world saves itself in the browser; **Make a new
world** in the menu starts over.

## Copying it

The game is `index.html` plus the `vendor/` folder beside it; copy both. three.js (MIT, its
licence in `vendor/three/LICENSE`) is the only third-party code.
